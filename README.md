# Capa a Capa

Tienda estática de productos impresos en 3D. No necesita instalar programas ni servidor: abre `index.html` para verla localmente.

## Publicarla gratis

La forma más directa es **GitHub Pages**:

1. Crea una cuenta en GitHub y un repositorio nuevo.
2. Sube todos los archivos y carpetas de este proyecto, conservando su estructura.
3. En el repositorio abre **Settings → Pages** y selecciona la rama `main` y la carpeta `/ (root)`.
4. GitHub mostrará una dirección pública en unos minutos.

También puedes arrastrar la carpeta del proyecto a Netlify Drop para obtener una URL temporal sin configurar nada.

## Pedidos y contacto

Cada producto enlaza a su anuncio de Wallapop, que es el canal de pedido. La web también incluye enlaces al perfil de Wallapop y a Instagram, Facebook y TikTok para consultas y novedades.
